# astrbot_plugin_fx（FX 多市场行情助手）

一个面向 **AstrBot** 的多市场免费实时行情查询与自选清单插件，支持加密货币（现货 / 永续合约）、A 股、港股、美股及全球主流大盘指数，内置自选清单管理与可选 LLM 辅助标的识别。

---

## 核心特性

- **零 Key 免费行情接口**：聚合 OKX、Binance Data Vision、Gate.io、东方财富、腾讯财经、新浪财经公开接口，自动多源容灾。
- **现货优先 + 合约显式/降级**：加密标的默认查询现货；可通过 `BTC合约` / `ETH-PERP` / `合约 SOL` 指定永续合约；若某币种无现货但有合约，自动降级为合约并标注 `[合约]`。
- **按用户区分的全局自选清单**：默认按发送者用户 ID 区分（同一用户在所有群聊与私聊共享同一份清单），首次默认初始化为全球核心大盘标的（`BTC`、`标普500`、`纳斯达克`、`沪深300`、`恒生指数`、`日经225`、`富时100`），也支持在配置中切换为按会话或全机器人共享。
- **LLM 辅助模糊与合集识别（可选）**：当机械规则与公开搜索未命中时，交由你在 WebUI 选定的 LLM Provider 自动识别（支持单个俗称如 `fx 数字黄金`，以及多标的合集如 `fx 美股七巨头`）。
- **红涨绿跌 / 绿涨红跌可切换**：默认红涨绿跌（`🔴+` / `🟢-`），支持在 WebUI 一键切换。

## 安装方式

1. **GitHub 仓库一键安装（推荐，支持后续直接更新）**：
   - 打开 AstrBot 管理面板 → **插件** → **安装插件**。
   - 输入仓库地址：`https://github.com/alphaply/astrbot_plugin_fx`。
2. **WebUI 上传 ZIP 安装**：
   - 打开 AstrBot 管理面板 → **插件** → **从本地上传**。
   - 选择 `astrbot_plugin_fx.zip` 上传并启用（首次安装会自动安装依赖 `httpx>=0.25.0`）。
3. **手动解压安装**：
   - 将 `astrbot_plugin_fx` 文件夹解压放入 AstrBot 的 `data/plugins/` 目录下并重启。

## 指令说明（默认触发词：`fx`，兼容 `/fx`）

| 指令 | 说明 | 示例 |
| :--- | :--- | :--- |
| `fx` | 查看当前自选清单的 24h 价格与涨跌幅 | `fx` |
| `fx <标的>` | 即时查询单个或多个标的（支持加密/A股/港股/美股/指数） | `fx btc`、`fx btc合约`、`fx 上证指数`、`fx 贵州茅台`、`fx aapl`、`fx btc eth sol` |
| `fx <模糊词/合集>` | 机械未命中且已选 LLM Provider 时自动 AI 识别并批量返回行情 | `fx 数字黄金`、`fx 美股七巨头`、`fx 宇宙行` |
| `fx 添加 <标的...>` | 批量添加到自选清单（别名：`add`、`+`；默认现货，无现货自动降级合约） | `fx 添加 BTC ETH SOL`、`fx 添加 BTC合约 上证指数` |
| `fx 移除 <标的...>` | 批量移出自选清单（别名：`删除`、`del`、`rm`、`remove`、`-`） | `fx 移除 BTC ETH`、`fx 移除 BTC合约` |
| `fx 帮助` | 查看插件使用帮助说明（别名：`help`、`?`、`？`） | `fx 帮助`、`fx help` |

## WebUI 配置项说明

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `command_keyword` | `fx` | 自定义触发关键词（同时匹配 `关键词` 与 `/关键词`，忽略大小写） |
| `enable_llm_fallback` | `true` | 机械接口查不到时是否启用 LLM 辅助识别 |
| `llm_provider_id` | `""` | 通过下拉框选择 AstrBot 中已配置的 LLM Provider（留空则不调用 LLM） |
| `default_watchlist` | `["BTC", "标普500", "纳斯达克", "沪深300", "恒生指数", "日经225", "富时100"]` | 新用户首次访问时自动初始化的默认自选标的 |
| `watchlist_scope` | `user` | 自选隔离粒度：`user`（按用户跨群全局同步）/ `session`（按会话独立）/ `global`（全机器人共享） |
| `color_style` | `cn` | 涨跌颜色风格：`cn`（红涨绿跌 `🔴涨 🟢跌`）/ `us`（绿涨红跌 `🟢涨 🔴跌`） |
| `show_source` | `true` | 是否在每条行情末尾附加数据来源标注（如 `[OKX]`、`[东财]`） |
| `proxy` | `""` | 可选 HTTP/HTTPS 代理（如 `http://127.0.0.1:7890`） |
| `request_timeout` | `10` | 单次行情 HTTP 请求超时时间（秒） |

## 免费行情数据源

- **加密货币现货**：OKX → Binance Data Vision → Gate.io
- **加密货币合约**：OKX Swap → Gate.io USDT Futures → Binance Futures
- **A 股 / 港股 / 美股 / 全球指数**：东方财富（搜索 + 行情）为主，腾讯财经、新浪财经为备用兜底
